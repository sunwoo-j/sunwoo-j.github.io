# 콘텐츠 작성 기준

이 문서는 지식 곳간의 새 글을 분류하고 출처를 표시하는 기준입니다. 기존 글의 URL과 분류는 보존하고, 새 글부터 적용합니다.

## 콘텐츠 분류

게시물마다 **가장 중심이 되는 카테고리 하나**를 지정합니다.

| 카테고리 | 포함할 내용 |
| --- | --- |
| `Dev Journal` | Delivery Simulator 등 개인 프로젝트의 진행 기록, 설계 선택, 문제와 결과 |
| `Game Design` | 게임 메커니즘, 플레이어의 선택과 동기, 레벨 디자인, 시스템 간 상호작용 |
| `UI/UX` | 인지심리학, 사용성, 정보 설계, 게임 인터페이스와 플레이 경험 |
| `Tech Notes` | 프로젝트와 학습 과정에서 얻은 프로그래밍·도구·기술 개념 |

`GDC Notes`는 독립 카테고리로 중복 생성하지 않고, `Game Design`에 포함되는 연재로 다룹니다. GDC 강연을 중심으로 한 글에는 `gdc-notes` 태그를 붙여 모아 볼 수 있게 합니다. 강연 분석 글이 여러 편 쌓이면 별도의 탐색 허브를 만들 수 있습니다.

기존 Discord 봇 글의 `Python`, `discord.py` 카테고리와 기존 UI/UX 글의 주소·분류는 그대로 둡니다. 태그는 주제, 도구, 장르처럼 서로 다른 글을 가로질러 묶을 때 사용하고, 같은 의미의 태그를 대소문자나 표현만 바꾸어 중복 등록하지 않습니다. Front Matter의 `date`, `description`, `categories`, `tags`를 빠짐없이 확인합니다.

## 출처와 인용

- 독자가 주장을 확인할 수 있도록 사실, 수치, 인용, 외부 사례가 나온 문장 가까이에 출처 링크를 둡니다. 글 끝에는 핵심 참고 자료를 다시 모아 둡니다.
- 가능한 경우 원 저작자·발표자·공식 문서·원 논문 등 1차 출처를 우선합니다. 2차 자료를 이용했다면 그 사실이 드러나게 링크합니다.
- 기술 정보가 버전이나 시점에 따라 바뀔 수 있으면 사용한 도구·버전과 확인 시점을 적습니다.
- GDC 강연 분석에는 강연 제목, 발표자, 개최 연도와 공식 영상 또는 세션 페이지를 표시합니다. 특정 주장이나 사례를 다룰 때는 가능하면 영상의 타임스탬프도 덧붙입니다.
- 발표자의 주장·사례와 글쓴이의 해석·비평·추가 제안을 구분해 씁니다. 영상의 흐름을 그대로 번역하거나 긴 구간을 옮기지 않고, 필요한 짧은 인용에만 출처를 붙인 뒤 자신의 분석을 중심으로 설명합니다.
- 이미지·도표·영상·코드 등 직접 만든 것이 아닌 자료에는 원 출처와 필요한 라이선스·저작자 표시를 함께 확인합니다. 사용 허가가 불분명한 자료는 복제해 올리지 말고 원본으로 연결합니다.
- 외부 자료를 바탕으로 한 설명이라도 글의 결론과 적용 아이디어는 글쓴이의 관점으로 작성하고, 근거가 부족한 부분은 사실처럼 단정하지 않습니다.

## 한국어·영어 글 관리

- 한국어 원문은 `_posts/`, 영문판은 `_translations/`에서 관리합니다. 영어 제목·설명을 원문의 `english_title`, `english_description`에도 반영합니다.
- 원문에는 `lang: ko`, `translation_url: /en/posts/<slug>/`를, 영문판에는 `lang: en`, `original_url: /posts/<slug>/`, `permalink: /en/posts/<slug>/`를 지정합니다. 기존 한국어 URL과 카테고리는 유지합니다.
- 영문판은 `layout: lily-post`를 사용하며, 이전·다음 글 링크도 영어 글로 연결합니다. 코드 예제의 명령어·출력·주석은 스크린샷과 맞도록 원문을 보존합니다.
- 초안의 영문판은 `published: false`로 둡니다. 번역을 추가했다는 이유로 초안을 공개하지 않습니다.
- 화면 문구는 `_includes/language-data.html`의 `ko`/`en` 사전과 `data-i18n` 속성으로 관리합니다. 언어 선택은 URL의 `lang`과 브라우저 저장소로 유지됩니다.
- 빌드 후 `python tools/check_languages.py`로 언어 연결, 내부 링크·이미지, 번역 키, 양쪽 코드의 일치, 초안 제외를 확인합니다. 모바일 메뉴와 검색·필터는 브라우저에서 확인합니다.

## 게시 전 확인 사항

- 이 글이 독자에게 전하는 핵심 질문이나 배움이 무엇인지 제목과 도입부에서 알 수 있는가?
- 카테고리가 글의 주된 목적 하나를 가리키며, 연재 글에는 일관된 태그가 있는가?
- 외부 사실·주장·사례를 확인할 수 있는 링크가 붙어 있는가?
- 이미지에는 내용을 설명하는 대체 텍스트가 있는가?
- 링크와 이미지가 공개 사이트에서 열리고, 기존 글로 연결한 주소가 유지되는가?
